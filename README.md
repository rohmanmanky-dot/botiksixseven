# Аргунский маршрут — путеводитель по Чечне

Проект по курсу «Основы российской государственности» (НИУ ВШЭ).
Это туристический маршрут на 10 остановок: от мечети «Сердце Чечни» в Грозном
через Аргунское ущелье до древнего некрополя Цой-Педе у границы с Грузией.
В финале — монета 10 ₽ «Чеченская Республика».

**Команда:** Рахман (презентация, карта, мечеть, водопады, монета),
Влад (о Чечне, характеристика маршрута), Миша (Ушкалойские башни, Цой-Педе).

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | сайт-путеводитель |
| `js/stops.js` | **все тексты, координаты и источники остановок** — правим здесь |
| `js/app.js` | карта (Leaflet + OpenStreetMap) и отрисовка карточек |
| `css/style.css` | оформление |
| `images/` | фото (список нужных файлов — в `images/README.md`) |
| `materials/plan.md` | кто что делает и что проверить перед защитой |
| `materials/presentation.md` | структура слайдов для защиты |

## Как посмотреть

Открыть `index.html` в браузере. Для карты нужен интернет.

Или по ссылке GitHub Pages (после включения: **Settings → Pages → Source: GitHub Actions**):
`https://rohmanmanky-dot.github.io/botiksixseven/`

## Как добавить свой текст

1. Открыть `js/stops.js` и найти свою остановку по `title`.
2. Заменить содержимое `text` (абзацы в `<p>…</p>`), удалить строку с `class="draft"`
   и поставить `draft: false`.
3. Источники дописать в `sources` в формате `["Название", "https://ссылка"]`.
4. Тексты Влада для разделов «О Чечне» и «Характеристика маршрута» — в `index.html`
   (жёлтые блоки ✍️).
