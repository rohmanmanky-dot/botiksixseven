# Аргунский маршрут — путеводитель по Чечне

Проект по курсу «Основы российской государственности» (НИУ ВШЭ).
Это туристический маршрут на 10 остановок: от мечети «Сердце Чечни» в Грозном
через Аргунское ущелье до древнего некрополя Цой-Педе у границы с Грузией.
В финале — монета 10 ₽ «Чеченская Республика».

**Команда:** Рахман (презентация, карта и остановки «по пути»),
Тихон (мечеть, водопады, монета), Влад (о Чечне, характеристика маршрута),
Миша (Ушкалойские башни, Цой-Педе).

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | сайт-путеводитель |
| `presentation.html` | **презентация для защиты** (слайды, интерактивная карта на 2-м слайде) |
| `js/stops.js` | **все тексты, координаты и источники остановок** — правим здесь |
| `js/app.js` | карта (Leaflet + OpenStreetMap) и отрисовка карточек |
| `css/style.css` | оформление |
| `images/` | фото (список нужных файлов — в `images/README.md`) |
| `materials/yandex-map.geojson` | все 10 точек и линия маршрута для импорта в [Конструктор карт Яндекса](https://yandex.ru/map-constructor) |
| `materials/plan.md` | кто что делает и что проверить перед защитой |
| `materials/presentation.md` | структура слайдов для защиты |

## Как посмотреть

Открыть `index.html` в браузере. Для карты нужен интернет.

Или по ссылке GitHub Pages (после включения: **Settings → Pages → Source: GitHub Actions**):
`https://rohmanmanky-dot.github.io/botiksixseven/`

## Как показывать презентацию

Открыть `presentation.html` в браузере (нужен интернет — для карты и шрифтов).

- **→ / ← / пробел / кликер** — листать, **F** — во весь экран.
- **N** — заметки для выступающего (полный текст автора внизу экрана).
- Внизу слева подписано, кто рассказывает слайд.
- На слайде 2 карту можно двигать, приближать и нажимать на точки.
- Запасной вариант без интернета: `Ctrl+P` → «Сохранить как PDF» (карта будет картинкой).

## Как добавить свой текст

1. Открыть `js/stops.js` и найти свою остановку по `title`.
2. Заменить содержимое `text` (абзацы в `<p>…</p>`), удалить строку с `class="draft"`
   и поставить `draft: false`.
3. Источники дописать в `sources` в формате `["Название", "https://ссылка"]`.
4. Тексты Влада для разделов «О Чечне» и «Характеристика маршрута» — в `index.html`
   (жёлтые блоки ✍️).

## Карта в Конструкторе Яндекса (рекомендован в задании)

1. Открыть [yandex.ru/map-constructor](https://yandex.ru/map-constructor), войти в Яндекс-аккаунт.
2. «Импорт» → выбрать `materials/yandex-map.geojson` → появятся 10 пронумерованных меток и линия маршрута.
3. Название карты: «Аргунский маршрут». При желании заменить прямую линию на маршрут по дорогам
   (инструмент «Линии»).
4. «Сохранить и продолжить» → скопировать ссылку на карту (её можно показать на защите или вставить в QR).
