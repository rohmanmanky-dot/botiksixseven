# 📚 Бот-староста для учебной группы

Телеграм-бот для чата группы: напоминает о лекциях и семинарах и собирает
перекличку «+ / −», чтобы старосте не приходилось вручную считать, кто придёт.

## Что он делает

- **Напоминает о паре** за 30 минут до начала (время настраивается — хоть для
  каждой пары своё): предмет, тип (лекция / семинар / практика), время,
  аудитория, преподаватель, ссылка на онлайн-пару.
- **Собирает перекличку** прямо в сообщении: кнопки `✅ Буду`, `❌ Не буду`,
  `🕐 Опоздаю`. Можно просто написать в чат `+` или `-` — бот засчитает ответ
  в последнюю активную перекличку и поставит реакцию.
- **Показывает старосте картину целиком**: кто ответил «+», кто «−», а кто
  промолчал (если загружен список группы).
- **Подводит итог** через 10 минут после начала пары и присылает сводку
  старостам в личку.
- **Отдаёт отчёт**: `/report` за день и `/export` в CSV (открывается в Excel).
- **Утренний дайджест** со списком пар на день.

Пример сообщения-переклички:

```
🔔 Пара через 30 минут

📝 Алгоритмы и структуры данных — семинар
🕘 14:40–16:00
📍 Покровский б-р 11, ауд. S-317 · Петрова А. С.
📅 15 сентября, вторник

✅ Будут (12): Ахмедов Рахман, Борисова Анна, …
❌ Не будут (2): Гаджиев Ислам, Дементьева Мария
🤔 Не ответили (3): Виноградов Пётр, …

Отметьтесь для старосты: кнопкой ниже или напишите в чат + / -
```

## Быстрый старт

### 1. Создать бота

Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
Там же: `/setprivacy` → **Disable** — иначе бот не увидит `+` и `-` в группе.

### 2. Поставить зависимости

```bash
git clone https://github.com/rohmanmanky-dot/botiksixseven.git
cd botiksixseven
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Настроить

```bash
cp .env.example .env                              # вставьте BOT_TOKEN
cp config/schedule.example.json config/schedule.json   # своё расписание
cp config/roster.example.json config/roster.json       # список группы (по желанию)
```

Свой Telegram ID для `ADMIN_IDS` можно узнать командой `/whoami` — напишите её
боту в личку после запуска.

### 4. Запустить

```bash
python -m bot
```

### 5. Подключить чат группы

Добавьте бота в чат, дайте права администратора (нужны для закрепления
сообщений) и отправьте в чате `/here`. Всё — бот запомнил, куда слать
напоминания. Альтернатива: указать `CHAT_ID` в `.env`.

## Команды

| Команда | Кто может | Что делает |
|---|---|---|
| `/today`, `/tomorrow`, `/week` | все | расписание на день / неделю |
| `/next` | все | ближайшая пара и сколько до неё |
| `/me Иванов Иван` | все | представиться, чтобы в отчёте были ФИО, а не ники |
| `/whoami` | все | свой Telegram ID и ID чата |
| `/here` | староста | привязать бота к этому чату |
| `/ask` | староста | запустить перекличку по ближайшей паре прямо сейчас |
| `/report [дата]` | староста | отчёт за день (`сегодня`, `вчера`, `2026-09-12`) |
| `/export [с] [по]` | староста | выгрузка отметок в CSV |
| `/reload` | староста | перечитать `schedule.json` без перезапуска |

Староста — это тот, чей ID указан в `ADMIN_IDS`, либо любой администратор чата.

## Файл расписания

`config/schedule.json`. Еженедельные пары кладутся в `lessons`, разовые
(контрольные, пересдачи) — в `extra` с полем `date`.

```jsonc
{
  "group": "БПИ-241",              // название группы, необязательно
  "timezone": "Europe/Moscow",
  "semester_start": "2026-09-01",  // от него считаются числитель/знаменатель
  "remind_before_minutes": 30,     // за сколько минут напоминать по умолчанию

  "lessons": [
    {
      "id": "algo-sem",            // уникальный, латиница/цифры/дефис
      "title": "Алгоритмы и структуры данных",
      "kind": "seminar",           // lecture, seminar, practice, lab, exam, test, other
      "weekday": "wed",            // mon…sun, «ср», или число 0–6
      "start": "14:40",
      "end": "16:00",              // необязательно
      "teacher": "Петрова А. С.",  // необязательно
      "location": "ауд. S-317",    // необязательно
      "link": "https://zoom...",   // необязательно, для онлайн-пар
      "parity": "all",             // all | odd (числитель) | even (знаменатель)
      "since": "2026-09-01",       // с какой даты действует
      "until": "2026-12-25",       // по какую
      "skip": ["2026-11-06"],      // разовые отмены
      "remind_before_minutes": 60, // своё время напоминания
      "note": "сдать домашку"      // приписка в напоминании
    }
  ],

  "extra": [
    { "id": "kr1", "title": "Контрольная", "kind": "test",
      "date": "2026-10-14", "start": "12:10", "end": "13:30" }
  ]
}
```

Русские названия тоже понимаются: `"kind": "лекция"`, `"weekday": "пн"`,
`"parity": "числитель"`.

После правки файла отправьте `/reload` — перезапуск не нужен.

## Список группы

`config/roster.json` нужен только для строки «не ответили». Формат — список
ФИО или объектов:

```json
{
  "students": [
    { "name": "Ахмедов Рахман" },
    { "name": "Борисова Анна", "telegram_id": 123456789 }
  ]
}
```

Студент связывается со своей записью либо по `telegram_id`, либо командой
`/me Ахмедов Рахман` (регистр, лишние пробелы и «ё/е» не важны).

## Настройки `.env`

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather (обязательно) |
| `CHAT_ID` | пусто | ID чата группы; проще задать через `/here` |
| `ADMIN_IDS` | пусто | ID старост через запятую |
| `TIMEZONE` | `Europe/Moscow` | часовой пояс |
| `REMIND_BEFORE_MINUTES` | `30` | за сколько минут напоминать |
| `DIGEST_AT` | `08:00` | время утреннего дайджеста (пусто — выключить) |
| `SUMMARY_AFTER_MINUTES` | `10` | когда после начала пары подводить итог |
| `SCHEDULE_PATH` | `config/schedule.json` | путь к расписанию |
| `ROSTER_PATH` | `config/roster.json` | путь к списку группы |
| `DB_PATH` | `data/bot.sqlite3` | база с отметками |

## Развёртывание

### Docker

```bash
docker compose up -d --build
```

### systemd

```ini
# /etc/systemd/system/group-bot.service
[Unit]
Description=Telegram bot for study group
After=network-online.target

[Service]
WorkingDirectory=/opt/botiksixseven
ExecStart=/opt/botiksixseven/.venv/bin/python -m bot
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now group-bot
```

## Частые вопросы

**Бот не реагирует на `+` в группе.** Отключите privacy mode у @BotFather
(`/setprivacy` → Disable) и перезайдите ботом в чат.

**Перекличка не приходит.** Проверьте, что отправляли `/here` в чате группы,
и что в расписании есть пары на ближайшие дни (`/next`).

**В отчёте ники вместо фамилий.** Попросите группу один раз написать боту
`/me Фамилия Имя` — дальше он помнит.
